# 图标资源说明

小程序需要以下图标文件（PNG 格式，81x81 像素）：

## Tab Bar 图标
- `icon-home.png` - 首页图标（未选中）
- `icon-home-active.png` - 首页图标（选中，黑色）
- `icon-daily.png` - 日盘图标（未选中）
- `icon-daily-active.png` - 日盘图标（选中，黑色）
- `icon-purchase.png` - 进货图标（未选中）
- `icon-purchase-active.png` - 进货图标（选中，黑色）
- `icon-alert.png` - 预警图标（未选中）
- `icon-alert-active.png` - 预警图标（选中，黑色）

## 建议
可以使用微信开发者工具自带的图标库，或者从 iconfont.cn 下载。
图标建议尺寸：81x81 像素，PNG 格式，透明背景。
